# Overview

Developed by Aarush & Riji (https://github.com/mirchidog), this is a single-level platformer created on Godot that is moderately difficult.
This is for Hack Club Haven (https://haven.hackclub.com)

# Lore

Bob (Jindal Barathi Bhawastani Shangguan Zhuge Martinez Bob) is a slime that needs to collect one specific flag that magically transports him to a liminal dimension known as "win screen".

# Development Story

So, we originally intended to have more features, but we had to start from square 1 with only 1:30 hours left. 
This is our incorporation of the "bounce back" theme, as we were resilient, and perservered.

# How To Play

Use either WASD or arrow keys. Discover the rest on your own. If you get stuck or fall, restart the game :P
